# world-population-analysis
World population data analysis using Python, pandas, and matplotlib.
=======
**World Population 2026 – Top 10 Countries**

1) This project visualizes the top 10 most populated countries in 2026 using a bar chart.
2) The dataset is sourced from Kaggle: World Population 2026.

***Key Points:***

1) X-axis: Country abbreviations (e.g., IND for India) for clarity
2) Y-axis: Population in 2026
3) Purpose: To provide a quick, clear comparison of the largest populations worldwide

*Libraries Used: pandas, matplotlib*

**Usage:**

1) Download the CSV file from Kaggle.
2) Update the file path in the code.
3) Run the notebook to view the bar chart of the top 10 most populated countries.
4) Dataset link:(https://www.kaggle.com/datasets/enwelumchiamaka/world-population-by-country-2026/code)
